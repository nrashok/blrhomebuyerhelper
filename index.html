How it works

Load a skill into Claude Code or claude.ai, describe your property, and start sharing documents.

1

Start a session

Tell Claude the property details — project name, survey number, K-RERA ID — and what documents you have.

2

Share documents

Upload documents as you collect them: K-RERA certificate, sale agreement, cost sheet, EC, khata, RTC, and more.

3

Track findings

Claude cross-checks each document against the checklist and maintains a live tracker: Verified, Flagged, or Open.

4

Get a report

Request a structured report: headline verdict, section-by-section walkthrough, and a close-out list of what's still needed.

Example session

You
I am evaluating Tower B, Unit 1202 in Cedar Crest Residences, Whitefield. Developer: Azure Vale Homes. K-RERA no. KR-1234567890-2025. I have the K-RERA certificate, sale agreement, cost sheet, and brochure.
Claude
I'll anchor this on Tower B, Unit 1202, not the project as a whole. I can verify the K-RERA and authority records live if web access is available.
You
Here is the K-RERA certificate and cost sheet. The unit is 1,240 sqft carpet; the cost sheet shows a DG backup of 3 kVA per flat.
Claude
3.1 ✓ Verified by the K-RERA certificate • 14.1 ✓ Verified from cost sheet • 6.4 ⚠ Flagged — DG note is not enough without the written allocation clause. Highest priority Open: 2.5 tower-specific OC and 3.3 final Fire NOC.

Karnataka portals referenced

The skills tell you exactly which portal to check for each item. Here are the major ones.

K-RERA — RERA registration & project status
Bhoomi — RTC & land records
e-Aasthi / e-Khata — BBMP property records
BBMP / GBA — Property tax & approvals
BDA / BMRDA — Layout approvals
Kaveri 2.0 — Registration & EC
BESCOM — Electricity connection
BWSSB — Water & sewerage
KSPCB — Environmental clearance
AAI NOCAS — Height clearance
Karnataka Fire — Fire NOC
BIAPPA / BMICAPA — Airport corridor planning
MCA — Company records
MUDA / KHB / KIADB — Development authorities

Getting started

Claude Code / Agent SDK

Copy the skill folder (e.g. skills/apartment-due-diligence-verifier/) into your project's skills directory, or point your skills configuration at this repository.

claude.ai

Create a new skill in claude.ai and paste in the contents of the relevant SKILL.md file. Start a conversation naming your property.
